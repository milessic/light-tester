# milessic-themes

`system.css` and `../css/previews.css` are vendored from
https://mjthemes.mikrus.dev/ on 2026-11-12. The bundle URL pins contract version
`1.12.0`; previews are unversioned by the upstream contract.

Upstream permits personal and commercial use with visible attribution linking
to the theme server. The app includes that attribution. See
https://mjthemes.mikrus.dev/manifesto (section 10) for the published terms.
The manifesto's separate `/LICENSE` link returned 404 when vendoring.
Application styles are separate in `app.css`.
